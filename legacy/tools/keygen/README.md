# 정품키 발급

웹 버전의 라이선스는 **서명된 개인별 정품키** 방식입니다. 서버 없이 이 PC 에서 키를 만들고, 앱은 공개키로 검증합니다.

- 체험판: 처음 사용한 날부터 **5개월**. 지나면 계산이 막히고 정품키 입력 창이 뜹니다. (시계를 과거로 되감으면 무효)
- 정품키: 이름과 사용 기한(선택)이 들어 있는 `GMR1-…` 문자열. 위조할 수 없습니다.
- 앱 안의 검사는 브라우저에서 돌아가므로 "정직한 사용자용" 수준입니다. 코드를 직접 고치거나 브라우저 저장소를 지우는 것까지는 막지 못합니다.

## 키 발급 (Node.js 만 있으면 됨)

```
cd legacy/tools/keygen
node keygen.mjs issue --name "홍길동"                    # 기한 없는 정품키
node keygen.mjs issue --name "홍길동" --expires 2027-12-31   # 2027-12-31 까지 쓸 수 있는 키
node keygen.mjs verify "<키>"                            # 키가 맞는지 확인
node keygen.mjs list                                     # 지금까지 발급한 목록
```

발급한 키는 화면에 한 번 출력되고, 발급 기록(이름, 기한, 날짜, 키)은 개인키 폴더의 `issued.csv` 에 쌓입니다.
받는 사람은 앱 오른쪽 위의 "체험판 · N일 남음" 버튼을 눌러 키를 붙여넣으면 됩니다.

## 개인키 (중요)

- 위치: `%USERPROFILE%\.gimun-license\private.pem` (이 저장소 밖이라 커밋되지 않습니다. `*.pem` 은 `.gitignore` 에도 들어 있습니다.)
- **반드시 백업하세요.** 잃어버리면 새 키를 발급할 수 없습니다. 이미 발급한 키는 계속 쓸 수 있습니다.
- 유출되면 누구나 키를 만들 수 있으므로, 새로 만들어(`init`) 앱의 공개키(`src/license/publicKey.ts`)를 바꾸고 다시 배포해야 합니다. 이 경우 예전 키는 모두 무효가 되니 새로 발급해야 합니다.
- 처음 한 번만: `node keygen.mjs init` (이미 개인키가 있으면 덮어쓰지 않고 멈춥니다)

## 키 형식

`GMR1-` + base64url(JSON 내용) + `.` + base64url(서명 64바이트). 서명은 ECDSA P-256 / SHA-256 입니다.
내용 예: `{"v":1,"n":"홍길동","e":"2027-12-31"}` (`e` 가 없으면 기한 없음)
